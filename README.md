# 电缆接头检测 — 产品培训手册 & 使用说明书

> 电缆中间接头关键参数监测系统 — 软件使用说明与操作人员培训参考

---

## 一、系统简介

本系统是一套专门用于**监测电缆中间接头关键参数**的智能监测系统，通过实时监测温度、湿度、气体浓度、烟雾、压力等关键参数，确保电缆接头的安全运行。

### 系统组成

| 设备   | 监测节点   | 说明           |
|--------|------------|----------------|
| 设备 1 | 1–5 节点   | 5 个监测点     |
| 设备 2 | 6–7 节点   | 2 个监测点     |
| 设备 3 | 8–9 节点   | 2 个监测点     |

- **共 9 个监测节点**，覆盖电缆接头关键位置。
- 本仓库内对应多个 Flutter 子项目：`sensor_flutter5`（1–5 节点）、`sensor_flutter67`（6–7 节点）、`sensor_flutter89`（8–9 节点）等。

### 主要监测参数

- **温度**：PT100 温度传感器，A/B/C 三相温度分布（外温 + 中内计算温度）
- **湿度**：环境湿度
- **气体**：氢气(H₂)、一氧化碳(CO) 浓度
- **烟雾**：白烟、黑烟浓度
- **压力**：环境压力

---

## 二、主要功能

1. **实时监测**：多节点温度、湿度、气体等参数实时展示，数据约每秒更新；按系统状态着色（正常/预警/故障/未连接）。
2. **预警与故障报警**：温度/气体/湿度/压力/烟雾超阈值预警与故障报警；连接状态监控，断线自动报警。
3. **历史数据**：自动保存为 CSV；支持按日期、按节点查看与导出。
4. **远程数据传输**：向远端服务器（Modbus TCP）发送节点状态、分钟级历史、预警/故障及实时数据。
5. **参数设置**：各参数阈值、温度修正值、PT100/环境温度修正、中内温度 k1/k2 系数等可配置。

---

## 三、密码与设置

- **管理员密码**：默认 `123456`；可在界面「修改密码」中修改，新密码至少 6 位，修改后立即生效。
- **系统设置**：温度/气体/湿度/压力阈值；各节点可独立设置阈值与修正值。
- **节点参数**：PT100 修正值、环境温度（上/中/下）修正、中内温度计算系数 k1、k2（默认 k1=6.42，k2=2.5）。

---

## 四、界面与操作流程（操作员）

1. **首页**：查看各节点状态卡片（正常/预警/故障/未连接），点击卡片进入该节点详情。
2. **节点详情页**：查看该节点温度（外温、中内）、湿度、压力、CO/H₂、烟雾及当前预警/故障列表；可进行参数设置、忽略规则管理。
3. **历史数据**：进入「历史数据」→ 按日期/节点查询 → 查看曲线与表格，用于事故追溯与趋势分析。
4. **文件管理**：查看、导出历史 CSV，管理保存路径。
5. **修改密码**：定期更换管理员密码，防止误改系统参数。

## 五、修正公式与显示（技术人员参考）

- **温度**：PT100 显示温度 = 原始温度 + 修正值；中内温度 Y = xi + k1×max(0, xi−x0i) + k2×max(0, xi−xia)。
- **烟雾**：变量 x0 = 568×(xStar−a)/T；浓度 m 按分段公式拟合。
- **压力**：压力值 = 1000×(原始值/8388608.0)−50。
- **温湿度**：温度 = −45+175×(原始值/65535)；湿度 = 100×(原始值/65535)。

显示精度：温度/湿度/压力一般为 1 位小数，烟雾可为 2 位小数；单位见界面（°C、%RH、ppm、%LEL、mg/m³、kPa）。

---

## 六、预警与故障逻辑（概要）

- **温度**：超过预警阈值预警，超过故障阈值故障；局放高（左外/右外比中间高 0.5°C 以上）可触发故障；中内超阈值故障。
- **气体**：H₂/CO/烟雾达预警/故障阈值分别预警或故障。
- **湿度**：超预警阈值预警；超故障阈值或预警持续达设定时长转故障。
- **压力**：超预警/故障阈值分别预警或故障。
- **连接**：超过约 10 秒无数据更新判定未连接并报警。

---

## 七、远端服务器与发送规则

- **目标**：192.168.201.203:502（Modbus TCP 标准端口）。
- **内容**：节点连接状态变化、每分钟历史数据、预警/故障信息、实时数据等；数据以 JSON 形式经 Modbus TCP 发送。
- **规则**：故障 5 分钟内不重复发送；预警 10 分钟内不重复发送；历史数据每分钟一次；连接状态变化立即发送。

---

## 八、数据存储与路径

- **默认路径**：系统文档目录下的 `logs/`；可按节点分目录（如 node_01、node_02），按日期文件（YYYY-MM-DD.csv）。
- **支持**：自定义保存路径、按时间范围与节点导出 CSV。

---

## 九、预警/故障忽略功能

- 已知可接受的预警/故障可设为「忽略」；被忽略项可不显示在界面。
- **操作**：节点详情页对单条预警/故障点「忽略」，或多选后「批量忽略」；需管理员密码；可设忽略期限或永久。
- **管理**：在设置中可查看、启用/停用、删除忽略规则；支持按节点、类型、过期时间管理。

---

## 十、通信与端口（参考）

- **本机 TCP 服务**：监听端口 **10123**（说明书）或 **10124**（部分代码实现），监听地址 0.0.0.0；用于接收现场设备数据。
- **远端 Modbus TCP**：客户端连接 192.168.201.203:**502**。
- 数据帧含节点 ID、帧类型、长度、数据及 CRC 校验；支持主动查询（如每 2 秒轮询节点）。

具体端口以当前运行子项目代码为准（如 `sensor_flutter5` 内 `modbus_tcp_server.dart`、`modbus_tcp_client.dart`）。

---

## 十一、注意事项与维护

- 定期检查传感器与网络连接，定期校准与备份历史数据。
- 勿随意修改系统参数；定期更换管理员密码。
- 出现故障及时处理并记录，必要时联系技术支持。
- 定期清理过期忽略规则与旧历史文件，注意存储空间。

## 十二、子项目与运行

本仓库为多节点监测的总体目录，包含多个 Flutter 应用子目录：

| 子目录            | 说明           |
|-------------------|----------------|
| `sensor_flutter5` | 1–5 节点监测   |
| `sensor_flutter5t`| 1–5 节点（可选变体） |
| `sensor_flutter67`| 6–7 节点监测   |
| `sensor_flutter89`| 8–9 节点监测   |
| `sensor_flutter89t`| 8–9 节点（可选变体） |

进入对应子目录后执行：

```bash
cd sensor_flutter5   # 或 sensor_flutter67、sensor_flutter89 等
flutter pub get
flutter run           # 或 flutter run -d windows / -d android
```

构建：

```bash
flutter build windows
flutter build apk
```
